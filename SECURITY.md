# Security Policy

## Reporting a Vulnerability

Ours Privacy maintains this SDK. If you believe you have found a security vulnerability, please **do not open a public issue**. Report it to **ciso@oursprivacy.com** and include steps to reproduce, the impact, and any suggested fix.

We will acknowledge your report within 1 business day and provide an initial assessment within 7 business days. We will notify you when the fix is released and credit you if you wish. Please give us a reasonable amount of time to respond before making any information public.

Use the same address for vulnerabilities in Ours Privacy services. See our [Trust Center](https://security.oursprivacy.com/) for more about our security practices.

## Supported Versions

We provide security updates only for actively supported versions. Older versions may not receive patches.

## Safe Harbor

We will not pursue legal action against security researchers who:

- Report vulnerabilities in good faith.
- Avoid privacy violations, data destruction, or service disruption.
- Provide us with a reasonable amount of time to remediate before public disclosure.

## SDK Generation

This SDK is generated with tooling from Stainless Software, Inc. Stainless does not maintain this SDK or handle its security reports, so please do not send reports there.
